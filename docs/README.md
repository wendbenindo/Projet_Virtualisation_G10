# Documentation du projet

Documentation technique à rendre avec le projet.

## Fichiers à créer

### 1. `architecture.md` (10-15 pages)
**Contenu requis:**
- Schéma d'architecture de l'infrastructure
- Description de chaque composant (lb1, app, bdd)
- Choix techniques justifiés
- Configuration réseau détaillée
- Processus de déploiement
- Gestion des secrets
- Extensions implémentées (E1, E2, E3, E4)

### 2. `journal_de_bord.md` (1-2 pages)
**Contenu:**
- Répartition des tâches dans l'équipe
- Chronologie du projet (semaine par semaine)
- Difficultés rencontrées et solutions
- Décisions importantes prises

### 3. `resultats_tests.md`
**Contenu:**
- Résultats de V1 à V6 avec mesures réelles
- Captures d'écran
- Graphiques de performance
- Analyse des résultats

### 4. `guide_utilisation.md`
**Contenu:**
- Installation pas à pas
- Commandes utiles
- Dépannage (troubleshooting)
- FAQ

## ⚠️ Important
- Chiffres réels et honnêtes (mesures inventées = -4 points)
- Schémas clairs et professionnels
- Pas de copier-coller du sujet
- Citer les sources si nécessaire
